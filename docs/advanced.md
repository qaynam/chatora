## 編集・保存

### 新規ページ

サイドバーで `n` を押すか、`:Chatora new` を実行すると、空のページが開きます。Cosense Web と同じく、
1 行目に書いた内容がタイトルになり、最初に保存した時点でページが作成されます。タイトルを書かずに
保存しようとすると、メッセージを表示して保存を中止します。

同じタイトルのページがすでに存在する場合は、そのページに統合するか確認します。統合すると、この
ページの本文（2 行目以降）が既存ページの末尾に追加され、統合先のページが開きます。統合しない場合は
保存されないため、タイトルを変更してから保存し直せます。

`:q` で閉じるときは、Neovim と同じ `Save changes to "…"?` という確認が表示されます。Yes を選ぶと
`:w` と同じ手順で保存し、同名のページがあれば統合するか確認します。No を選ぶと変更を破棄して閉じ、
Cancel を選ぶとバッファに戻ります。1 行目を書いてカーソルを離れると、バッファ名もそのタイトルに
変わるため、確認メッセージにもタイトルが表示されます。

保存するまでは、バッファに `無題` という仮の名前が付いています。`:Chatora new タイトル` のように
タイトルを指定すれば、指定したページを直接開けます。

### タイトルの変更

1 行目がタイトルです。Cosense Web と同じく、1 行目を書き換えるとページ名が変わります。カーソルが
タイトル行を離れたとき（Insert モードではモードを抜けたとき）、または `:w` を実行したときに確認が
表示されます。確認に答えると、その場でタイトルも保存されます。確認が終わるまではタイトルを
サーバーへ送信しません。その間も本文の自動保存は続きますが、本文と一緒に送られるタイトルは変更前の
ままです。

ほかのページからリンクされている場合は、「N 個のページがリンクしています。リンクも書き換えますか？」
と確認されます。書き換えると、プロジェクト内の `[旧タイトル]`、`#旧タイトル`、`[旧タイトル.icon]` が
新しいタイトルに更新されます。書き換えない場合は新しいタイトルのページが作成され、旧タイトルへの
リンクは実体のないページを指す赤リンクになります。Esc で確認を閉じると何も変更されません。タイトルを
書き直すか、`:w` をもう一度実行してください。

Cosense では、同じタイトルのページを複数作成できません。既存のタイトルに変更しようとすると、
次の 3 つから選択します。

| 選択               | 動作                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| 統合する           | 本文（2 行目以降）を既存ページの末尾に追加し、このページを削除します。統合先のページが開きます           |
| 別の名前で保存する | Cosense が末尾に番号を付け、`タイトル_1` のような別のページとして保存します                           |
| やめる             | 何もしません。タイトルを書き直すか、`:w` をもう一度実行します                                             |

統合先のページを別のウィンドウで開いている場合は、追加された行が同期によって反映されます。

### 同期と競合

開いているページは、バックグラウンドでサーバーと同期します。サーバーの内容を単純に上書きするの
ではなく、変更をマージするため、**ローカルで編集した内容が一方的に消えることはありません**。

```lua
edit = { sync = { interval = 30, on_focus = true, notify = true } }  -- 既定
edit = { sync = false }                                              -- 手動（pull のキー）だけにする
```

`interval` はポーリングの間隔（秒）です。画面に表示されているバッファだけを同期し、そこから
離れると停止、戻ると再開します。`on_focus` を有効にすると、ページを開いた直後にも一度同期します。
`notify` を有効にすると、取り込んだ内容と競合の件数を通知します。

マージは行ごとに、行 ID で突き合わせます。そのため、サーバー側で行が並べ替えられたり挿入されたり
しても、ローカルの編集はもとの行についていきます。

| 状況                                     | 結果                                       |
| ---------------------------------------- | ------------------------------------------ |
| 別々の行を編集した                       | 両方の変更が反映されます                     |
| 同じ行を同じ内容に編集した               | 競合は発生しません                           |
| 同じ行を異なる内容に編集した             | **ローカルの内容を残し**、競合として示します   |
| ローカルで編集した行をサーバーが削除した | **ローカルの行を残し**、競合として示します     |
| ローカルで削除した行をサーバーが編集した | サーバー側の行が復元され、競合として示します   |

最後のケースだけはローカル側の削除を優先しません。削除操作はやり直せますが、削除された文章は
復元できないためです。

競合した行は、行のハイライトと行末の `◆ サーバー: …` で示します。`<<<<<<<` のようなマーカーを
バッファへ書き込むことはありません。`]c` で次の競合行へ移動できます。

保存時に競合が発生した場合はサーバーへ書き込まず、マージ結果を表示したうえでバッファを未保存の
まま残します。内容を修正してから、もう一度 `:w` を実行してください。

### 箇条書き

Cosense では、インデントに使う文字（半角スペース、タブ、全角スペース）が 1 文字分で 1 段として
扱われます。Chatora は各行のインデントの深さに合わせて中点を表示し、1 段を 1 マスで表します。
ページバッファでは `tabstop` を 1 にしているため、タブも 1 マスになり、2 マス幅の全角スペースは
1 マスに見えます。そのため、**どの文字でインデントした行も、同じ深さにそろえて表示されます**。

```lua
view = { pads = {
  bullet = '•',      -- 中点に使う文字
  guide = false,     -- 文字を指定すると上位レベルに縦線を表示（Cosense にはない）
  spacing = false,   -- true で 1 段を 2 マスに広げる
  gap = 0,           -- 中点と本文の間に追加する余白
} }
```

`spacing = true` にすると Cosense Web に近い、幅広の段になります。ただし、長い行を折り返した
ときに 2 行目以降が本文の位置にそろわなくなります。Neovim の折り返し時の字下げは、インデントの
文字数だけを基準にするためです。

`1.` で始まる行は番号付きリストとして扱われるため、中点を表示しません。

インデントに使う文字をそろえたいときは `<leader>cI` を使います。すべてのインデントを半角スペース
1 個ずつに書き換えます（段数は変わりません）。見た目は変わらないため、異なる種類の空白が混在して
手で編集しづらいページに便利です。**インデントのあるすべての行が編集扱いになる**ため、次の保存時に
それらの行がまとめて送信されます。

### 引用

`> 引用` の `>` を縦棒に置き換え、本文には Cosense Web と同じ薄い背景を行の右端まで表示します。
本文の文字色は変わりません。リストの中では縦棒が中点の隣に表示され、`> ` は隠れます。

```lua
view = { quote = {
  bar = '▌',                                   -- 太さは文字で指定: ▏ ▎ ▍ ▌ ┃ │
  hl = { fg = '#4493f8' },                     -- 縦棒（ChatoraQuoteBar）
  text_hl = { bg = '#2a2a2a' },                -- 引用本文（ChatoraQuoteText）
  dim = true,                                  -- 背景の代わりに本文を Comment 色で表示
  wrap = false,                                -- 折り返し行に縦棒・背景を表示しない
} }
```

`hl` と `text_hl` は `nvim_set_hl` にそのまま渡されます。省略した場合、背景には colorscheme の
地の色から少しずらした色を使い、縦棒は `Comment` の色で表示します。`text_hl = false` にすると
縦棒だけを表示します。縦棒は、カーソルがその行に移動しても消えません。

`wrap = true`（既定）にすると、折り返された引用の 2 行目以降にも縦棒と背景を表示します。

### 折り返し

長い行を折り返すと、2 行目以降は本文の 1 文字目にそろえて表示されます。中点や引用の縦棒の分だけ
字下げし、その位置から縦棒を続けて表示します（`breakindent`）。

ページのウィンドウでは `linebreak` を無効にしています。Neovim の `linebreak` は `breakat` に
指定された文字（空白や `.`、`@`、`/` など）の位置でしか折り返さないため、日本語のまとまりが
次の行へ移動して上の行に空白ができたり、`` `@architecture.md` `` のようなコード片が `.` の位置で
分割されたりします。`wrap` 自体は変更しません。

### 画像の貼り付け

`<leader>cv` でクリップボードの画像をアップロードし、カーソルの下の行に画像記法を挿入します。
アップロード中は、その行にスピナーが表示されます。

クリップボードから画像データを取得するには外部ツールが必要です。利用できるもののうち、最初に
見つかったツールを使います。

| プラットフォーム | ツール                                                            |
| ---------------- | ----------------------------------------------------------------- |
| macOS            | `pngpaste`（`brew install pngpaste`）。見つからない場合は標準の `osascript` |
| Wayland          | `wl-paste`                                                        |
| X11              | `xclip`                                                           |

アップロード先はプロジェクト側の設定（`uploadImageTo`）で決まります。`gcs` の場合はプロジェクトの
ファイル領域へアップロードし、`[https://scrapbox.io/files/….png]` を挿入します。`gyazo` の場合は
Gyazo へアップロードし、`[https://gyazo.com/…]` を挿入します。設定を読み取れない場合はプロジェクト
のファイル領域を使い、片方へのアップロードに失敗した場合はもう片方を試します。

### リンクの貼り付け

Cosense のページ URL を貼り付けると、ページへのリンク記法に変換します。Cosense Web の編集画面と同じ動作です。

| 貼り付けたもの                     | 挿入されるもの              |
| ---------------------------------- | --------------------------- |
| 現在開いているプロジェクトのページ | `[ページ名]`                |
| 別のプロジェクトのページ           | `[/other-project/ページ名]` |
| 行 ID 付きの URL                   | `[ページ名#行ID]`           |

貼り付けた内容が URL 1 つだけの場合に変換します。文章に URL が混ざっている場合や、
プロジェクトのトップページ（`https://scrapbox.io/my-project`）はそのまま挿入します。タイトルに `[` や `]`
を含むページも、リンク記法では表現できないため URL のまま挿入します。`code:` ブロックの中では
変換しません。ブロック内は記法として解釈されないため、変換すると URL が失われるからです。

ターミナルからの貼り付け（Insert モードを含む）でも、`p` / `P` でも動作します。
`edit = { paste_link = false }` を指定すると、何も変換しません。

### リンク補完

`[` を押すと `[]` が入力され、その中にページの候補が表示されます。候補には、プロジェクト内の
既存ページと、まだ存在しないページ（赤リンク）が含まれます。

候補が表示されるのは**通常のページリンクの中だけ**です。`[* 見出し]` のような装飾記法や、`[$ x^2]`、
`[taro.icon]`、`[https://…]`、`[/別プロジェクト/ページ]` の中では表示されません。候補を選ぶと
括弧内の文字列全体が置き換わるため、ほかの記法の中で候補を表示すると、入力中の内容を壊すおそれが
あるためです。装飾記法を書き始めた時点（`[* ` まで入力した時点）で候補の表示は止まります。
そのため、見出しを書いている途中でメニューがちらつくこともありません。

装飾の中に書いたリンクは素のリンクなので、`[* [ページ]]` の内側では候補が出ます。

`#` のあとでも同じ候補が表示されます。タイトルに空白があるページは、空白を `_` に置き換えて
挿入します。Cosense ではタイトルの空白と `_` を同じものとして扱うため、`#Side_Kanban` は
`[Side Kanban]` と同じページを指します。ただし、`#`、`[`、`]`、全角スペースを含むタイトルは
タグで表現できないため、タグの候補には表示されません。

### アイコン挿入

アイコンキー（`<C-i>` / `<M-i>`）は、押す場所によって動作が変わります。

| 状況                                       | 挿入されるもの                                                  |
| ------------------------------------------ | --------------------------------------------------------------- |
| リンク補完が開いていて候補が選択されている | 選択中のページのアイコン `[候補.icon]`（入力中の `[...]` ごと置換） |
| それ以外                                   | 自分のアイコン `[自分.icon]`                                    |

blink.cmp、nvim-cmp、Neovim 標準の補完のいずれでも動作します。ただし、ターミナルのポップアップには
画像を表示できないため、補完メニュー内にアイコンは表示されません。

### 保存状態の表示

保存結果は、トーストではなく小さなアイコンで通知します。サイドバーの `●` マーク、コマンドライン
への 1 行の表示、statusline のコンポーネントで確認できます。

`component()` は保存状態のアイコンを、`page_info()` はページ情報の文字列を返します。

```lua
-- 素の statusline
vim.o.statusline = "%f %{%v:lua.require'chatora.status'.component()%} %{v:lua.require'chatora.status'.page_info()}"

-- lualine
{ sections = { lualine_x = {
  { function() return require('chatora.status').page_info() end,
    color = function() return require('chatora.status').page_info_hl() end },
} } }
```

`page_info()` は `更新 43分前 · 閲覧 39 · 被リンク 6` のような文字列を返します。ページ以外の
バッファでは空文字を返すため、条件分岐なしでそのまま使えます。色は `page_info_hl()` が
ハイライトグループ名として返します。

Cosense の日時はサーバー側に保存された内容を基準にしています。そのため、ローカルに未保存の変更が
ある場合は、先頭に未保存を示すバッジを付けます。

| 状態     | `page_info()`                      | `page_info_hl()`       |
| -------- | ---------------------------------- | ---------------------- |
| 保存済み | `更新 43分前 · 閲覧 39`            | `ChatoraStatusMuted`   |
| 未保存   | `● 未保存 · 更新 43分前 · 閲覧 39` | `ChatoraStatusDirty`   |
| 保存中   | `◍ 保存中 · …`                     | `ChatoraStatusPending` |
| 保存失敗 | `✗ 保存失敗 · …`                   | `ChatoraStatusError`   |

更新時刻だけなら `require('chatora.status').updated(bufnr)` です。色を自前で付けるなら、
`require('chatora.status').icon(bufnr)` がアイコンとハイライトグループ名を返します。

## 表示

### 記法の色

既定の色は colorscheme から取得しますが、**同じ色を複数の意味に使いません**。Cosense Web では
フォントサイズで表現する強調の段階を、ターミナルでは色で表現するためです。リンクの色や別の段階と
同じ色になると、異なる意味に見えてしまいます。

| 記法                       | 既定の見た目                         |
| -------------------------- | ------------------------------------ |
| `[link]` / `[/proj/page]`  | リンク色（下線なし）                 |
| 外部 URL                   | 同じ色 + **下線**                    |
| `` `code` `` / `code:js`   | 灰色の背景バッジ（文字色はそのまま） |
| `[* 見出し]`               | 太字のみ                             |
| `[** 見出し]`              | 太字 + 色（リンク色とは必ず別）      |
| `[*** 見出し]` 以上        | 太字 + さらに別の色                  |
| 実体のないページへのリンク | `ChatoraLinkEmpty`（既定は赤）       |

すべて `default = true` で定義しているので、`:hi` で上書きできます。

```lua
vim.api.nvim_set_hl(0, '@lsp.type.bold3.cosense', { fg = '#ff8700', bold = true })
vim.api.nvim_set_hl(0, '@lsp.type.code.cosense', { bg = '#303030' })
```

### テロメア

行の左に、その行がいつ書かれたかを表すバーを表示します。これは Cosense の
[テロメア](https://scrapbox.io/help-jp/テロメア)に相当する表示です。ページ全体の更新時刻だけでは
分からない、**どの行が**更新されたのかを確認できます。

| 見た目 | 意味                                                                 | ハイライトグループ       |
| ------ | -------------------------------------------------------------------- | ------------------------ |
| 太さ   | 新しい行ほど太くなります。直近 1 時間が `█`、季節をまたぐと `▏` です |                          |
| 青     | 前回の訪問より後に更新された行（未読）                               | `ChatoraTelomereUnread`  |
| 濃い青 | このバッファを開いた後に更新された行（同期で入ってきた）             | `ChatoraTelomereUpdated` |
| 地の色 | 前回の訪問より前から変わっていない行                                 | `ChatoraTelomere`        |
| 変更色 | 自分が編集した、まだ保存していない行                                 | `ChatoraTelomereLocal`   |

バーはサインカラムに表示します。`signcolumn` が `no` のウィンドウでは、自動的に `yes:1` へ変更します。

サインカラムのバーは、現在画面に表示されている行だけを対象にします。ページ全体のどこに更新が
あるかは、ウィンドウ右端のスクロールバーで確認できます。淡い帯は現在表示中の範囲、色付きのマークは
更新された行の位置を示します。ページ全体を高さに対応させて表示するため、**画面外の更新も確認できます**。
`]u` / `[u` で更新された行を順番にたどれます。`mouse` が有効なら、バーをクリックして移動することもできます。

1 画面に収まるページには表示しません。スクロールする必要がなく、全行のバーがすでに見えているためです。
すべての行が更新済みの場合も、特定の行を示す必要がないためマークを表示しません。

```lua
view = { telomere = { bar = true, scrollbar = false } }  -- 右端のマークだけやめる
view = { telomere = false }                              -- どちらも出さない
```

色はどれも `default = true` で定義しているので、colorscheme の後に
`vim.api.nvim_set_hl(0, 'ChatoraTelomereUnread', { fg = '#89a3ff' })` のように上書きできます。

### 赤リンク

実体のないページを指すリンクは、色を変えて示します（`ChatoraLinkEmpty`、既定は赤）。

判定にはプロジェクトのタイトル索引を使い、Cosense と同じルール（小文字化、空白とアンダースコアの
同一視）で照合します。`[Side Kanban]` と `[side_kanban]` は同じページとして扱われます。

タイトル索引は 5 分間キャッシュします。ただし、このセッション中に判明した変更はすぐに反映します。

| 出来事                           | 索引                                                     |
| -------------------------------- | -------------------------------------------------------- |
| 新規ページを保存した             | タイトルを追加します（リンクがすぐに赤でなくなります） |
| ページを削除した                 | タイトルを削除します                                     |
| リンク先のページが存在しなかった | タイトルを削除します                                     |

### カスタム装飾記法

`[<記号> 本文]` の記号に、独自の装飾を定義できます。

```lua
notations = {
  ['|'] = { name = 'highlight', hl = { bg = '#3a3a00', bold = true } },
  ['='] = { name = 'boxed',     hl = { link = 'WarningMsg' } },
  ['@'] = { name = 'heading', icon = '📌', hl = { bold = true }, rule = true },
}
```

| フィールド | 説明                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------- |
| キー       | 1 文字の記号。公式記法の記号（`* / - _ $ [`）とは併用できません                           |
| `name`     | 英数字と `_` のみ。semantic token の型名になります                                        |
| `hl`       | `nvim_set_hl` にそのまま渡されます。`:colorscheme` を変えても再適用され、文字色は `fg` です |
| `icon`     | 開きマーカーの代わりに表示する 1 文字。カーソル行では元の記号が表示されます                   |
| `rule`     | `true` で行の下にウィンドウの右端まで届く罫線を表示します。色は `rule_hl` です            |

記号は連ねて指定できます。Cosense のマーカーは 1 文字ではなく記号の組み合わせとして解釈されるため、
組み合わせた記号の装飾がすべて適用されます。

```
[|* 特徴]      -- highlight（上の例）と 太字
[|= 両方]      -- highlight と boxed が重なる
[!' お願い]    -- ! だけ設定していれば ! の見た目。' は何もしない
```

装飾が重なったとき、競合しない属性（片方が `bg`、もう片方が `fg` と `bold` など）はそのまま合成されます。
同じ属性が競合した場合は**先に書いた記号が優先されます**。カスタム記法は公式記法（`*` `/` `-` `_`）より
優先されます。

Cosense が記号として認める文字（`!"#%&'()*+,-./{|}<>_~`）は、設定していなくても記号の組み合わせの一部
として扱います。そのため、`[!' お願い]` が「`!' お願い` というページへのリンク」になることはありません。
設定していない記号だけの `[' x]` は、これまでどおりリンクとして扱われます。

設定に誤りがあっても、プラグイン全体が停止することはありません。`icon` が 2 文字以上の場合はその
`icon` だけを無効にします。記号が 1 文字でない、`name` が不正、公式記法と衝突する場合は、その
エントリ全体を無視して `vim.notify` で通知します。`hl` を Neovim が受け付けられなかった場合は、
原因になったキー名も通知します。

### ファイルへのリンク

Cosense にアップロードしたファイル（`https://<origin>/files/<id>.<ext>`）へのリンクには、開き括弧の位置に
アイコンを表示します。

```
[report.html https://scrapbox.io/files/….html]   -- 󰈔 report.html
```

括弧はもともと隠して表示するため、行の幅は変わりません。アイコンは `view.file_icon` で変更できます。
1 文字でない値を指定した場合は無視し、括弧だけを隠して表示します。

### 画像の表示

アイコン記法や画像リンクをバッファ内に表示するには、対応ターミナル（kitty / Ghostty など）と
ImageMagick（`brew install imagemagick`）、画像表示用のプラグインが必要です。

```lua
-- 推奨: image.nvim（magick_cli プロセッサなら luarocks 不要）
{ '3rd/image.nvim', opts = { processor = 'magick_cli' } },
-- 代替: snacks.nvim の image モジュール（両方あれば image.nvim 優先）
```

画像は Chatora の LSP サーバーが PAT 付きで取得し、ローカルにキャッシュします。そのため、プライベート
プロジェクトのアイコンも表示できます。取得した画像は長辺 2048px に縮小してから端末へ送ります。
端末は表示中の画像を展開した状態で保持し、上限（Ghostty は 320MB）を超えると古い画像から破棄します。
画像を 1 枚ずつそのまま表示すると、サイズの大きな画像によってほかの画像が押し出されることがあるためです。

画像が表示されないときは、`:Chatora images` で各画像の状態を確認できます。`:Chatora images redraw` で
再描画できます。取得した画像は URL の先の画像が変わらないため、`~/.cache/chatora/assets` に残ります。
`:Chatora images clear` でキャッシュをすべて削除し、画像を再取得できます。

`[[…]]`（大きい記法）は、画像とアイコンの両方に使えます。`[[name.icon]]` が 1 行だけにある場合は
`image.height_large` の大きさで表示し、文中にある場合は通常の 1 行の高さで表示します。

GIF は端末のグラフィックプロトコルが静止画しか合成できないため、最初のフレームだけを表示します。
通常の Gyazo だけでなく、チーム Gyazo の画像も表示できます。

#### VS Code で画像を表示する

VS Code の内蔵ターミナルは sixel と iTerm inline images に対応していますが、kitty graphics protocol
には対応していません。そのため、snacks.nvim では画像を表示できず、image.nvim の sixel バックエンドに
切り替える必要があります。

1. VS Code の `settings.json` で画像を有効にします。設定後、ターミナルを開き直してください。

   ```json
   { "terminal.integrated.enableImages": true }
   ```

2. image.nvim のバックエンドをターミナルごとに切り替えます。バックエンドは setup 時に決まるため、
   ここで切り替えないと、Ghostty に sixel を送って画像が表示されなくなります。

   ```lua
   {
     '3rd/image.nvim',
     opts = {
       backend = vim.env.TERM_PROGRAM == 'vscode' and 'sixel' or 'kitty',
       processor = 'magick_cli',
     },
   }
   ```

3. sixel の生成には ImageMagick を使うため、SIXEL コーダーを含む ImageMagick が必要です。
   `magick -list format | grep -i SIXEL` を実行し、`SIXEL* SIXEL rw-` が表示されれば利用できます。
   Homebrew 版の ImageMagick には含まれています。

Chatora 側の `image.backend` は、既定の `'auto'` のままで構いません。image.nvim があれば優先して
使われ、プロトコルの選択は手順 2 の設定に任せられます。

### 画像だけの行

`[img1] [img2] [img3]` のように画像だけが並ぶ行は、Cosense Web と同じく、**同じ大きさのタイルを横に
並べて**表示します。写真はタイルいっぱいに広げ、はみ出した部分を切り落とします。ウィンドウ幅に
収まらない画像は、次の段へ折り返します。

```lua
image = { gallery = true }                          -- 既定。高さは image.height、タイルは幅 3 : 高さ 4
image = { gallery = { rows = 12, aspect = 4 / 3 } } -- 高さ 12 行で、横長のタイル
image = { gallery = 12 }                            -- 高さだけ変える
image = { gallery = false }                         -- 並べず、文中と同じ 1 行の高さで置く
```

`aspect` はタイルの幅を高さで割った値です。複数の画像を並べた 1 枚の画像はサーバーが ImageMagick で
生成します。ImageMagick がない場合は画像を 1 枚ずつ縦に表示します。画像が 1 枚だけの行は切り抜かず、
元の比率のまま表示します。

### 描画バックエンドを差し替える

画像をどのプロトコル（kitty / sixel / iTerm）で送るかは image.nvim や snacks.nvim 側で設定します。
Chatora は、どちらのプラグインを使うかだけを選択します。

```lua
image = { backend = 'auto' }        -- 既定。image.nvim を優先し、なければ snacks
image = { backend = 'image_nvim' }  -- 固定
image = { backend = 'snacks' }
```

端末ごとに切り替えたい場合は、関数を渡します。この関数は描画のたびに呼び出され、バックエンド名を
返すことも、バックエンド自体を返すこともできます。

```lua
-- kitty プロトコルが通る端末では snacks、通らない VS Code では sixel に設定した image.nvim
image = { backend = function()
  return vim.env.TERM_PROGRAM == 'vscode' and 'image_nvim' or 'snacks'
end }
```

image.nvim を `backend = 'sixel'` にすると、その Neovim では常に sixel を使います。`'auto'` のままだと
kitty にしか対応していない端末（Ghostty など）で画像が表示されなくなるため、両方の端末を使う場合は
前述のように端末ごとに切り替えてください。

| 端末                      | 通るプロトコル   | 使うもの                                    |
| ------------------------- | ---------------- | ------------------------------------------- |
| kitty / Ghostty / WezTerm | kitty graphics   | snacks か image.nvim（`backend = 'kitty'`） |
| VS Code 統合ターミナル    | sixel・iTerm IIP | image.nvim（`backend = 'sixel'`）           |

どちらのプラグインも、端末がグラフィックスに対応しているかを環境変数で判定します。VS Code の
統合ターミナルのように判定されない端末では、判定を無効にしてください。

```lua
{ 'folke/snacks.nvim', opts = { image = { force = true } } }  -- 判定を無視して送る
```

それでも合わない場合は、独自の描画処理を渡せます。テーブル（読み込み順の都合がある場合は、テーブルを
返す関数）に `place` を実装してください。

```lua
image = { backend = {
  --- bufnr の (row, col) に path の画像を置き、閉じ方を返す。描けなければ nil。
  --- geom = { row(1始まり), byte_col, byte_end, screen_col, indent_col, indent_screen_col,
  ---          align_indent }、opts = { height | max_height, max_width }。
  --- path は必ずローカルファイル（取得とキャッシュは Chatora 側で完了済み）。
  place = function(bufnr, path, geom, opts)
    local handle = my_renderer.draw(bufnr, path, geom.row, geom.screen_col, opts)
    if not handle then
      return nil
    end
    return {
      close = function() handle:clear() end,
      -- 省略可。true=表示中 / false=表示できない（Chatora が再描画） / nil=不明
      ok = function() return handle:visible() end,
    }
  end,
} }
```

`place` のないテーブルを渡した場合は、1 回だけ警告を表示し、既定のバックエンドに戻ります。

## 移動

### 行リンク

`[ページ名#<行ID>]` は、ページ内の特定の 1 行を指します。`gd` でページを開くと、**その行に
カーソルを移動します**。指定した行がすでに削除されている場合は、ページの先頭を表示します。

タイトルには `#` を含めることもできます（`[C#入門]` は 1 ページへのリンクです）。そのため、末尾が
行 ID の形式（16 進数 24 桁）に一致する場合だけ、行参照として扱います。

### 別プロジェクトのページ

`[/other-project/page]` に `gd` すると、そのプロジェクトのページが開きます。Cosense の公開プロジェクトは
誰でも読めますが、編集できるのはメンバーだけです。そのため、**自分がメンバーでないプロジェクトの
ページは読み取り専用で開きます**。バッファは `nomodifiable` になり、statusline には `読み取り専用` と
表示されます。バックグラウンドでの同期も行いません。

編集しようとすると、権限がないプロジェクトを通知します。メンバーかどうかを確認できなかった場合は
書き込み可能な状態で開き、保存時にサーバーから拒否された時点で通知します。

### リネームされたページ

Cosense はページをリネームしても、旧タイトルから現在のページへリダイレクトします。Chatora はこの
リダイレクトをたどるため、リネーム前に作成されたリンクからでも現在のページを開けます。同じ origin
内のリダイレクトだけを対象にします。

### 動画を再生する

Gyazo の動画（GIF キャプチャを含む）は、本文には静止画として表示されます。端末上では動画を再生
できないため、`gd` を実行したときの開き先を `open_video` で指定します。

```lua
open_video = 'open'                          -- macOS の既定のプレイヤー
open_video = { 'mpv', '--loop', '{url}' }    -- コマンドと引数（'{url}' が置き換わる）
open_video = function(url)                   -- 独自に処理する。false を返すとブラウザで開く
  vim.system({ 'mpv', url }, { detach = true })
  return true
end
open_video = 'browser'                       -- 既定。ほかのリンクと同じくブラウザ
```

渡される URL は、通常の Gyazo では `https://i.gyazo.com/<hash>.mp4` で、そのままプレイヤーで
再生できます。チーム Gyazo の場合は、プレイヤーページの URL が渡されます。

### ページ情報

`<leader>ci` で開きます。よく使う情報を上に配置し、区切り線の下に詳細な情報を表示します。

```
  URL          https://scrapbox.io/my-project/設計メモ
  作成         ◍ taro        3日前
  更新         ◍ はなこ      12分前
  共同編集者   ◍ ◍ ken、mika
  ─────────────────────────────────────
  プロジェクト my-project
  ページ履歴   12
  被リンク     6
  ─────────────────────────────────────
  閲覧数       128
  ページランク 1.23
  行数 / 文字数 42 / 1980
  ピン留め     なし
  最終閲覧     5時間前
```

日時は相対表記で表示します。作成者と最終更新者のアイコンは、画像を表示できるターミナルでは名前の
左に表示されます。画像を表示できない場合も名前は表示され、列の位置はずれません。共同編集者の行は、
作成者・最終更新者以外に編集したユーザーがいる場合だけ表示されます。

### サイドバーとプロジェクト

サイドバーには、**現在開いているページのプロジェクト**が表示されます。別プロジェクトへのリンクを
`gd` で開いたり、`:Chatora open <url>` を実行したりすると、サイドバーもそのプロジェクトに切り替わります。
元のページに戻ると、サイドバーも元のプロジェクトに戻ります。カーソル位置は変わりません。

一度取得したプロジェクトの一覧は Neovim を終了するまで保持するため、プロジェクトを移動するたびに
再取得する必要はありません。サイドバーを閉じて開き直した場合も、再読み込みは行いません。

`P` のピッカーには、保存済みのすべてのアカウントのプロジェクトが表示され、先頭の列にアカウント名が
表示されます。プロジェクトを選ぶと、必要に応じてアカウントも切り替わります。
